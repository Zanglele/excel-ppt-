# Excel 月报图表与 PPT 工具

一款面向设备运行月报的 **Python 桌面应用**。导入 Excel 后，可以核对数据、生成统计图表，再导出可在 PowerPoint 中继续编辑的汇报页面，减少每月重复筛选数据、计算指标和排版的工作。

应用使用 PyQt6 构建界面、pandas 计算统计指标、matplotlib 预览图表，并通过 python-pptx 生成原生可编辑图表。日常数据处理在本机完成，无需联网，源 Excel 文件不会被修改。

> **当前支持：两份 Excel → 七张图表 → 四页 PPT。**
> 完整规划为三份 Excel 生成五页 PPT；第三步“未解决的问题统计”目前仅预留入口，待统计规则确定后开发。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| Excel 导入 | 支持 `.xlsx`，可切换工作表、指定表头行、刷新数据 |
| 自动匹配字段 | 根据常用列名自动选择数据列，也可从全部列中手动修改 |
| 统计周期设置 | 自定义年份、汇报月份和月度趋势起始月份 |
| 设备运行统计 | 按产品类别和质保标记生成三张 Uptime / 跑货量双轴组合图 |
| 问题统计 | 生成年度问题数、月度趋势、问题密度和关闭率四张图 |
| 图表 detail | 查看每张图的统计目的、筛选条件、坐标、公式、字段和当前列映射 |
| 图表预览与核对 | 支持单图查看、问题统计四图总览，以及数据核对表 |
| 数据异常提示 | 提示缺失值、错误日期、非数值内容、未知山头等，帮助定位 Excel 行 |
| 图表样式 | 统一字体和默认配色；设备运行图支持自定义柱形与折线颜色 |
| 可编辑 PPT | 单独导出三页或一页，也可合并导出四页，保留图表内嵌数据 |

## 报告包含哪些内容

### 第一步：Uptime 与跑货量（3 页）

导入表格1后，按以下规则生成三页 PPT，每页一张双轴组合图：

| 页码 | 图表内容 | 分类规则 |
| --- | --- | --- |
| 1 | PX 产品 Uptime 与 Run货量 | 入质保非光学产品：XRF、XPS、XRD、AFM |
| 2 | 光学产品 Uptime 与 Run货量 | 入质保光学产品：BFI、DFI、DBO、IBO、eMBI、PC、MBI |
| 3 | 未入质保机台 Uptime 与 Run货量 | 客户名称单元格直接填充为黄色的记录，不区分光学与非光学 |

左侧纵轴显示 **Uptime 百分比折线**，右侧纵轴显示 **跑货量柱形**。横轴按三行展示机台编码、山头和客户名称，标题自动带入所选年份及月份。

黄色记录只进入第三页。每条 Excel 记录单独展示，不自动平均 Uptime 或合计跑货量。

### 第二步：问题统计（1 页）

导入表格2后，四张图统一使用所选年份的数据：

| 图表 | 类型 | 计算方法 |
| --- | --- | --- |
| 各山头总问题数 | 柱状图 | 按山头分组计数，每条有效记录视为一个问题 |
| 各山头月度问题趋势 | 多折线图 | 按山头和月份计数，连续显示起始月至结束月，缺失月份补 0 |
| 各山头问题密度 | 柱状图 | 该山头问题数 ÷ 该山头非空机台编码的去重数 |
| 各山头关闭率 | 柱状图 | 关闭记录数 ÷ 该山头问题数，以百分比显示 |

关闭记录的状态为 **申请关闭、已结束、已取消**，比较前去除首尾空格。问题数按行计数，重复记录也会计入；机器数在各山头内分别去重。

四张图按 **2×2 排列在 PPT 上半页**，下半页留白，方便补充总结和批注。仅绘制所选年份实际出现的山头，多条折线使用不同颜色。

### 第三步：未解决的问题统计（规划中）

计划使用表格3生成一页三图。未解决状态的定义、统计截止时间、三张图的维度及计算公式尚待确定，当前不会导入第三份表或生成第五页。

## 快速开始

### 直接使用 Windows EXE

已有分发包时，无需安装 Python：

1. 将 `ExcelPPT-Windows-x64.zip` **完整解压**。
2. 双击解压目录中的 `ExcelPPT.exe`。
3. 保留旁边的 `_internal` 文件夹；包内附有使用说明和两份模拟 Excel，可先试用流程。

导出 PPT 无需安装 PowerPoint；查看和编辑导出的文件需要兼容的演示文稿软件。

### 从源码运行

在 Windows 项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

已有虚拟环境时，可跳过第一条命令。使用 PyCharm 时，选择项目的 `.venv\Scripts\python.exe` 作为解释器，运行 `app.py`。

## 每月使用流程

1. **设置周期**：填写年份、汇报月份和趋势起始月份，满足 `1 ≤ 起始月 ≤ 结束月 ≤ 12`。
2. **导入 Excel**：进入对应步骤，选择文件和工作表。默认第一行为表头；如有标题或说明行，修改表头行后点击刷新。
3. **确认数据列**：核对自动匹配结果，必要时手动选择。下拉框显示全部列及列字母，空表头列也会保留。
4. **查看统计口径**：点击图表旁的 **detail**，检查公式、筛选条件和当前列映射，也可修改该图需要的字段。
5. **生成并核对**：查看图表和数据核对页，处理预警。各“制作图”按钮会重新计算该步骤，并切换到指定图表。
6. **导出报告**：分别导出第一步三页、第二步一页，或在两步均生成有效结果后合并导出四页。

同一步骤共用字段映射。修改年月、字段、数值格式、工作表或表头后，相关旧结果会失效，需要重新生成才能导出。在 Excel 中修改源文件后，请先保存，再回到应用点击刷新。

## Excel 数据准备

### 表格1：设备运行数据

| 客户名称 | 山头 | Uptime | 跑货量 | 机台编码 |
| --- | --- | --- | --- | --- |
| 示例客户甲 | XRF | 98% | 1200 | SN-001 |
| 示例客户乙 | MBI | 0.97 | 850 | SN-002 |
| 示例客户丙 | BFI | 95 | 600 | SN-003 |

以上仅为格式示例。未入质保记录需要在 Excel 中将**客户名称单元格直接填黄**，整行填黄也支持。机台编码建议保存为文本，以保留前导零。

**表格1应预先整理为要汇报的当月数据。** 当前未配置日期字段，因此年份和月份用于图表标题，不会自动筛选表格1的行；隐藏行和筛选隐藏的行也会读取。

### 表格2：问题记录

| 山头 | 创建时间 | 产品序列号/机台编码 | 服务请求状态 |
| --- | --- | --- | --- |
| XRF | 2026-3-1 | SN-001 | 已结束 |
| XRF | 2026-4-2 | SN-001 | 处理中 |
| MBI | 2026-4-3 | SN-002 | 申请关闭 |

创建时间支持 `20xx-x-xx`、Excel 日期单元格及带时间的日期。年度问题数、密度和关闭率包含**所选年份的全部有效记录**；只有月度趋势受起始月和结束月限制。

## 数据校验与统计约定

| 情况 | 程序处理 |
| --- | --- |
| 未导入文件 | 禁用相关生成按钮 |
| 必要列未匹配 | 提示手动选择，不直接退出 |
| Uptime 或跑货量缺失 | 提示机台编码和 Excel 行号；保留为空，不转换成 0 |
| 两项运行数值同时缺失 | 同样预警；该记录的缺失值保留为空 |
| 非数值、负数、异常 Uptime | 提示具体位置，阻止生成 |
| 日期无法解析 | 列出异常行，修正后重新生成 |
| 问题记录的机台编码为空 | 计入问题数，不计入机器数，并提示 |
| 问题记录的状态为空 | 计入问题数，不计入关闭数，并提示 |
| 比值分母为 0 | 显示 `N/A`，PPT 内嵌数据保持为空 |
| 整个统计范围无记录 | 提示“当前时间范围无有效数据”，不生成空白图 |
| 未知山头 | 提示核对；问题统计保留该名称；表格1未标黄的未知山头需修正后生成 |

表格1的三个分类都必须有可绘制数值，才能生成并导出完整三页。表格2所选年份及整个趋势区间都须有问题记录；对已出现的山头，区间内缺失月份仍按 0 绘制。

### Uptime 数值格式

默认自动识别，统一转换为 0～100% 显示：

| Excel 原值 | 自动模式的显示结果 |
| --- | --- |
| 文本 `98%` | 98% |
| 普通数值 `0.98` | 98% |
| 普通数值 `98` | 98% |
| 普通数值 `1` | 100% |
| 普通数值 `0` | 0% |

自动模式将普通数值 0～1 视为比例。如果 `0.5` 实际表示 **0.5%**，请手动选择“百分制”模式。应用另保留“按 Excel 格式”和“全部按小数比例”选项。

### 黄色标记与字段名称

- 标准山头名称忽略首尾空格和大小写，例如 `embi` 规范为 `eMBI`。
- 支持客户单元格直接纯色填充的 RGB、索引色和主题黄色，以及合并客户／山头单元格的继承读取。
- 仅其他列标黄或使用黄色字体，不会改变质保分类。
- 不计算条件格式的最终显示颜色；客户列含条件格式时，需改为直接填充后导入。

### 文件与记录

- 当前支持 `.xlsx`；旧版 `.xls` 请先另存为 `.xlsx`。
- 公式使用 Excel 保存的缓存结果；缺少缓存时，需在 Excel 中重新计算并保存。
- 纯空白行忽略；合计、说明和重复表头应移出数据区。
- 不自动截断记录或只显示 Top N。记录较多时横轴标签会变密，可在 PowerPoint 中继续调整版式。

## 图表与 PPT 样式

- **标题**：微软雅黑、16 pt、加粗，自动带入统计年份或年月。
- **默认配色**：柱形 `#ED7D31`，折线 `#5B9BD5`；多折线采用以蓝色开头的不同颜色序列。
- **自定义颜色**：第一步支持修改柱形与折线颜色，即时同步至预览和导出；第二步使用固定默认配色。
- **页面比例**：16:9；问题统计页下半部保留空白。
- **继续编辑**：PPT 使用原生图表，可编辑内嵌数据，也可复制至自己的汇报模板；演讲者备注记录来源和统计说明。

## 开发与验证

| 模块 | 职责 |
| --- | --- |
| `app.py` | 应用入口 |
| `excel_visualizer/main_window.py` | 主窗口、运行数据页面与合并导出交互 |
| `excel_visualizer/data_service.py` | Excel 读取、填充色识别、运行数据校验与分类 |
| `excel_visualizer/issues_service.py` | pandas 问题统计计算 |
| `excel_visualizer/issues_page.py` | 问题统计导入、预览和数据核对 |
| `excel_visualizer/details.py` | 图表说明与字段映射交互 |
| `excel_visualizer/chart_widget.py`、`issues_widget.py` | matplotlib 图表预览 |
| `excel_visualizer/chart_style.py`、`issues_charts.py` | 配色与问题图表定义 |
| `excel_visualizer/ppt_service.py` | 可编辑 PPT 生成 |
| `tests/` | 统计、界面、导出与版式验证 |
| `tools/`、`packaging/` | Windows 打包及分发包验证 |

运行测试和生成模拟报告：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tests/validate_issues_layout.py
```

测试覆盖统计口径、缺失值、列映射、结果失效、PPT 双轴和内嵌数据、四图布局及保存失败处理。模拟工作簿、PPT 和截图输出到 `outputs/问题统计功能验证/`。安装了 PowerPoint 的 Windows 电脑还可使用 `tests/render_powerpoint.ps1` 进行只读渲染检查。

### 构建 Windows 分发包

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe tools/build_windows.py
```

每次构建输出到新的 `releases/<构建时间>/` 目录，包含程序文件夹、ZIP 和构建信息，不覆盖旧包。旧 EXE 不会随源码修改自动更新。

对生成的 ZIP 运行验证：

```powershell
.\.venv\Scripts\python.exe tools/check_windows_package.py "releases/<构建时间>/ExcelPPT-Windows-x64.zip"
```

验证程序会解压 ZIP，移除 Python 环境路径后运行 EXE 自检，检查窗口、Excel 导入与三页／一页／四页导出，并将结果保存到 `outputs/EXE 验证/`。模拟数据验证不能替代真实业务数据和目标电脑上的验收。
