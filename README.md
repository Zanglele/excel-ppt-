# Excel 月报图表与 PPT 工具

三步月报工作流的桌面工具。当前支持第一步的 Uptime / 跑货量月报，以及第二步的问题统计：分别导入 Excel、核对统计、预览图表，并单独或合并导出可编辑的 PowerPoint。

## 工作流与当前范围

| 步骤 | 数据来源 | 计划产出 | 当前状态 |
| --- | --- | --- | --- |
| 1. Uptime 与跑货量 | 第一份 Excel | 3 页 PPT，每页 1 张双轴组合图 | 已实现，支持自定义柱状图和折线图颜色 |
| 2. 问题统计 | 第二份 Excel | 1 页 PPT，包含 4 张图表 | 已实现，上半页 2×2 排列，下半页留白 |
| 3. 未解决的问题统计 | 第三份 Excel | 1 页 PPT，包含 3 张图表 | 仅预留页签，内容留白 |

最终目标是导入三份 Excel 后合并导出五页 PPT。**当前可单独导出第一步三页、第二步一页，或合并导出前两步四页**。第三步尚未实现，不会添加空白第五页。切换步骤页签会保留已读取的数据、配色和图表。

## 自定义图表颜色

在窗口顶部的“汇报设置”中，点击 **柱状图 / 跑货量** 或 **折线图 / Uptime** 按钮，使用颜色选择器或输入 HTML 色号（如 `#208040`）。按钮同时显示色块和当前色号。

- 导入前可以选色；已有图表时改色会即时刷新三张预览图，无需重新读取 Excel 或重新计算数据。
- 三张图共用一组配色，导出 PPT 的柱体、折线和折线标记使用同样的颜色。预览柱体使用不透明填充，避免透明度使选色变浅。
- 点击 **恢复默认配色**，恢复蓝色柱体（`#4F81BD`）与橙色折线（`#D45A32`）。取消颜色对话框会保留原设置。
- 配色在本次程序运行期间保留，重新打开程序后恢复默认；当前不支持逐客户、逐图设置不同颜色。

## 固定的三张图

| 页码 | 分类 | 产品范围 |
| --- | --- | --- |
| 1 | 入质保、非光学 | XRF、XPS、XRD、AFM |
| 2 | 入质保、光学 | BFI、DFI、DBO、IBO、eMBI、PC |
| 3 | 未入质保 | 所有客户名字单元格标黄的记录，包含上述名单之外的产品 |

每张图使用同一横轴：**产品名称 + 客户名字**。**左纵轴是 Uptime 百分比折线，右纵轴是跑货量柱形**。先按以上产品顺序排列，同一产品内保留 Excel 行顺序。第三张图中名单以外的产品排在已知产品之后。

黄色记录只进入第三张图，不再进入前两张图。没有数据的分类保留对应页，并注明“本月无符合条件的数据”，因此第一步始终为三页，不额外添加封面。

## 安装和运行

在项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

已有 `.venv` 时，跳过创建环境步骤，更新依赖后运行即可。在 PyCharm 中选择项目的 `.venv\Scripts\python.exe` 为解释器，运行 `app.py`。导出不需要安装 PowerPoint；打开和编辑生成的文件需要兼容的演示文稿软件。

## 每月使用步骤

1. 在第一步页签点击 **导入第一份 Excel**，选择本月 `.xlsx` 文件。
2. 选择本月数据所在的 **工作表**，设置 **表头行**。例如第 1 行是月报标题、第 2 行才是字段名称，则填 `2`，点击 **读取工作表 / 刷新**。
3. 确认 **客户名字、山头 / 产品、Uptime、跑货量** 四个字段。程序会匹配常见列名，未匹配到的列需要手动选择。
4. 确认 **Uptime 格式** 和 **汇报月份**。同一工作表应只包含要汇报的当月数据；月份输入框仅用于 PPT 标注，不会筛选 Excel 行。
5. 点击 **生成三张月报图表**，切换三个图表页查看。在 **数据核对** 页检查原始行号、分类和转换后的数值。
6. 按需在顶部设置柱状图、折线图颜色，点击 **导出第一步 PPT（3 页）**，选择保存位置。PPT 使用原生图表，选中图表后可通过 PowerPoint 的“编辑数据”修改内嵌数据，也可复制到已有汇报模板。

更改字段、Uptime 格式、工作表或表头行后，旧图表会失效，必须重新生成才能导出。若在 Excel 中修改过文件，请保存后点击“读取工作表 / 刷新”。

## 第二步：问题统计

1. 切换到 **2. 问题统计（1 页）**，点击 **导入第二份 Excel**。
2. 选择工作表及表头行，确认 **山头、创建时间、产品序列号/机台编码、服务请求状态** 四列。支持自动匹配列名，也可手动选择。
3. 默认“密度 / 关闭率范围”为 **全部年份**；需要同一年度口径时，可切换为 **仅 2026 年**。前两图固定统计 2026 年，不受该选项影响。
4. 点击 **生成四张问题统计图表**，查看四图总览、单图和数据核对页。小窗口下四图总览可滚动查看。
5. 点击 **导出第二步 PPT（1 页）**；前两步均生成有效统计后，也可在顶部点击 **合并导出前两步 PPT（4 页）**。

| 图表 | 统计规则 |
| --- | --- |
| 左上：2026 年总问题数 | 创建时间前四字符为 `2026` 的行，按山头逐行计数，重复行也计数 |
| 右上：月度问题趋势 | 从 2026 年 1 月至电脑当前月份，缺失月份补 0；按第二份表中不同山头名称确定折线，每条线不同颜色 |
| 左下：问题密度 | 该山头总问题数 ÷ 该山头内非空机器编号的去重数 |
| 右下：关闭率 | 状态属于“申请关闭、已结束、已取消”的行数 ÷ 该山头总问题数，显示百分比 |

- **山头名单**：保留第一步的十种山头（XRF、XPS、XRD、AFM、BFI、DFI、DBO、IBO、eMBI、PC），第一步生成结果中的额外山头也会同步加入。第二份表中新出现的名字追加保留并提示，不丢弃。零问题山头仍保留柱图横轴位置。名称忽略首尾空格和大小写。
- **日期**：支持 `2026-1-2`、带时间的 `2026-1-2 09:30:00` 和 Excel 日期单元格。无效的 2026 年日期、缺失日期或山头会报出行号并阻止生成。2026 年晚于本月的记录计入年度总数，但不进入月度趋势。2026 年之后运行时，2026 年趋势显示完整 1—12 月。
- **机器和状态**：编号按山头分别去重；文本前导零保留，首尾空格忽略。空编号不计为机器，但问题数仍计入，会提示密度可能偏高。状态缺失仍计入分母，但不计关闭数。`已关闭` 等其他文字不会自动归并为已结束。
- **N/A**：机器数为 0 时密度为 N/A；问题数为 0 时关闭率为 N/A。PPT 内嵌数值保持为空，并在对应横轴名称下标注 N/A。
- **布局**：16:9 页面，上半页按两行两列放置四张原生可编辑图表，下半页不放页脚、说明或占位文字，供在 PowerPoint 中添加总结批注。数据来源和计算规则写入演讲者备注。界面四图预览用于核对图表，不是整页 PPT 截图。
- **更新数据**：改工作表、表头、字段或统计范围后，必须重新生成第二步；修改第一步的山头名单后，也会要求重新生成第二步。任一步结果失效时，合并导出自动禁用。Excel 外部修改后需保存并点击“读取工作表 / 刷新”。
- 顶部汇报月份和自定义颜色仍用于第一步；第二步的趋势范围使用电脑日期，采用固定的不同山头配色。

## 第一步 Excel 数据约定

建议结构如下（数值仅为格式示意）：

| 客户名字 | 山头 | uptime | 跑货量 |
| --- | --- | --- | --- |
| 客户甲 | XRF | 98% | 1200 |
| 客户乙 | BFI | 97.5 | 850 |
| 客户丙（客户单元格填黄） | XPS | 95% | 400 |

- **黄色标记**：读取客户名字单元格的直接纯色填充，支持标准黄色、常用浅黄、金黄色及 RGB、索引色、主题色和明暗变化。整行标黄也可以，因为包含客户单元格。只把产品或数值单元格标黄，不会改变质保分类；黄色字体也不作为未入质保标记。
- **条件格式**：当前不计算条件格式的最终显示颜色。客户列包含条件格式时会阻止生成，要求改为直接黄色填充，避免误判。渐变或图案填充也需要改为纯色。
- **合并单元格**：客户和产品的合并区域继承左上角名称及填充；不会把一般空白单元格任意填成上一位客户。每条记录的 Uptime 和跑货量应有独立数值，不能靠合并数值单元格表示多行。
- **重复记录**：同一产品、同一客户出现多行时逐行显示并提示，不会自动平均 Uptime 或合计跑货量。需要汇总时请先按确定的业务口径整理 Excel。
- **产品名称**：忽略首尾空格和大小写，例如 `embi` 规范为 `eMBI`。未标黄、又不属于指定十种产品的记录会报出具体行号，不会静默省略。
- **数值校验**：Uptime 必须为 0–100%，跑货量为有限非负数，允许真实的零值。缺失、文本错误、负数和异常百分比会阻止导出并提示行号，不用零填补错误数据。跑货量支持 `1,200` 这样的千位分隔文本。
- **公式**：读取 Excel 保存的计算结果。公式没有缓存结果时，需要在 Excel 中重新计算并保存后导入。
- **数据范围**：读取所选工作表表头以下的所有记录，包括隐藏行和筛选隐藏的行；纯空白行忽略。请移除数据区中的合计行、说明文字和重复表头，以免其被当作客户记录。
- **大量记录**：保留所有记录和横轴标签，不做 Top N 截断。单图超过 30 条记录时会提示横轴可能较密，可在 PowerPoint 中调整字号或版式。
- **原文件**：仅以读取方式使用 Excel，源文件不会被修改。

### Uptime 格式说明

| Excel 内容 | 默认“按 Excel 格式” | “全部按百分制” | “全部按小数比例” |
| --- | --- | --- | --- |
| 文本 `98%` | 98% | 98% | 98% |
| 数值 `0.98`，Excel 单元格格式为 `0%` | 98% | 0.98% | 98% |
| 数值 `98`，普通格式 | 98% | 98% | 超出范围，报错 |
| 数值 `0.98`，普通格式 | 0.98% | 0.98% | 98% |

默认遵循你描述的百分制。无百分比格式的 `0.98` 可能代表 0.98% 或 98%，程序不会自行猜测；若源数据用小数比例存储，手动选择对应模式。

## 模块与验证

- `app.py`：桌面程序入口。
- `excel_visualizer/data_service.py`：Excel 值、颜色、数字格式读取，校验和三类分组。
- `excel_visualizer/chart_widget.py`：matplotlib 双轴组合图预览。
- `excel_visualizer/chart_style.py`：预览与 PPT 共用的配色配置及色号校验。
- `excel_visualizer/main_window.py`：三步页面、配色、工作表、字段选择、数据核对和导出交互。
- `excel_visualizer/issues_service.py`：问题次数、月度趋势、机器去重、关闭率及异常校验。
- `excel_visualizer/issues_charts.py`、`issues_widget.py`：第二步共用图表数据与配色，以及 Qt 四图 / 单图预览。
- `excel_visualizer/issues_page.py`：第二份 Excel 的独立导入、字段匹配、统计核对和导出交互。
- `excel_visualizer/ppt_service.py`：第一步三页、第二步一页及合并四页 PPT 的原生图表和内嵌数据导出。
- `tests/test_monthly_report.py`：模拟数据测试，覆盖 Excel 填充色、合并、校验、分类、界面状态、选色到 PPT 的完整链路，以及 PPT 图表轴与内嵌数据。
- `tests/test_issues_report.py`：第二步统计、跨年 / 月份边界、零分母、内嵌数据、四图布局、独立及合并导出测试。
- `tests/validate_issues_layout.py`：生成模拟 Excel、示例 PPT 和离屏截图，保存到 `outputs/问题统计功能验证/`。

## 后续改进建议（尚未实现）

1. **确定第三步统计口径**：明确未解决状态、三张图的维度，区分“截至月末未解决”和“当前仍未解决”。
2. **补齐五页报告组装**：在现有 3 + 1 页的导出基础上，接入第三份 Excel 的独立校验、统计和第五页。
3. **记住常用设置**：保存配色、字段映射、表头行、Uptime 格式和最近目录，并提供重置入口。按 Excel 模板区分字段配置，减少每月重复选择。
4. **大表读取与导出放到后台**：目前 Excel 读取、表格填充和 PPT 导出都在界面线程中完成，大文件处理期间可能无法响应操作。可增加后台任务、阶段进度和取消；数据核对表改为按需显示，减少大量单元格控件的开销。
5. **增加导出前整页预览与版式设置**：当前预览只显示 matplotlib 图表，PPT 使用另一套渲染和页面排版。可增加带月份、页脚的整页预览，提供字号、标签换行、图例位置和跑货量单位设置。固定五页要求下，大量客户应优先调整版式，不应默默截断记录。
6. **让错误定位和报告追溯更直接**：将数据错误与 Excel 行号、列名关联，支持点击定位及导出错误清单；记录所用文件、工作表、月份和统计口径。月份输入可改为月份选择器，并明确它目前仅标注 PPT、不筛选数据。
