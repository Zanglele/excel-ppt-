# Excel 月报图表与 PPT 工具

Python / PyQt6 桌面应用：openpyxl 读取 Excel 数值、格式和填充色，pandas 计算问题统计，matplotlib 预览，python-pptx 导出原生可编辑图表。源 Excel 只读，不修改原文件。

## 当前交付范围

- 表格1：三页 Uptime 与 Run货量组合图，分别为入质保非光学、入质保光学、黄色标记的未入质保。
- 表格2：一页四图，上半页 2×2 排列，下半页留白。
- 支持分别导出三页、一页，或合并前两步四页。
- 表格3和第五页仍预留：用户尚未定义未解决问题的筛选条件、三图维度及计算公式，不生成虚构统计或空白第五页。

## 运行

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

也可在 PyCharm 选择项目 `.venv\Scripts\python.exe`，运行 `app.py`。

## 每月操作

1. 顶部填写统计年份、结束月份、月度趋势起始月份；月份必须满足 1 ≤ 起始月 ≤ 结束月 ≤ 12，同一年内统计。
2. 导入对应的 `.xlsx`，默认第一行为表头；可选择工作表、调整表头行并刷新。旧版 `.xls` 需另存为 `.xlsx`。
3. 下拉框列出全部 Excel 列（附列字母，空表头也保留），程序匹配常用字段名，未匹配时选择“请选择对应列”，由用户手动指定。
4. 点击生成按钮。各图旁的 **detail** 展示名称、统计目的、筛选条件、横纵轴、公式、涉及字段、自动匹配列、当前选择及注意事项；也可在 detail 中修改该图所需字段。
5. 查看单图预览和数据核对，再导出 PPT。各“制作图”按钮会重新计算该步骤并切换到指定图。同一步共用字段映射，修改映射后需重新生成。

修改统计年月、字段、数值模式、工作表或表头会使相关旧结果失效，禁用导出。文件在 Excel 中被修改后，需保存并点击刷新。

## 表格1：Uptime 与 Run货量

必选字段：客户名称、山头、Uptime、跑货量、产品序列号/机台编码。机台编码建议在 Excel 中保存为文本，以保留前导零。

- 非光学：XRF、XPS、XRD、AFM。
- 光学：BFI、DFI、DBO、IBO、eMBI、PC、MBI。
- 黄色客户单元格所在记录进入未入质保组，不再进入前两组；整行标黄也支持。仅其他单元格标黄不会改变质保分类。
- 名称去首尾空格，并对标准山头忽略大小写。未知山头提示：未标黄的未知山头阻止生成，标黄的未知山头保留到第三组。
- 支持直接纯色 RGB、索引色和主题黄色；支持合并客户/山头单元格继承。条件格式最终颜色无法可靠识别，会提示改为直接填充；不把黄色字体作为标记。
- 横轴三行依次是机台编码、山头、客户；左轴 Uptime 折线，右轴跑货量柱形。逐行保留，不自动平均或求和。
- 标题依次为 `PX产品xxxx年X月Uptime&Run货量`、`光学产品xxxx年X月Uptime&Run货量`、`T2～未入质保已经Run机台xxxx年X月Uptime&Run货量`。
- 表格1必须自行整理为所选月份数据：未指定日期字段，所以年月用于标题，不筛选表格1记录。读取范围包含隐藏及筛选隐藏的行。

Uptime 默认自动识别：文本 `98%` → 98%，普通数值 `0.98` → 98%，普通数值 `98` → 98%。0～1 普通数值视为比例，1 → 100%；若原值 0.5 表示 0.5%，请选择“百分制”模式。另保留按 Excel 数字格式和全部比例模式。

缺少任一数值或两项均为空时，弹窗列出机台编码和 Excel 行号；缺失值保留为空，预览断线/缺柱，PPT 内嵌数据为空，绝不填0。非数值、负数、无穷大、超过100%的 Uptime、无缓存公式会阻止生成并提示位置。真实0保留为0。

若整个分类没有记录或所有记录都没有任何有效数值，提示“当前时间范围无有效数据”，不生成该空白图，也不允许导出不完整三页。

## 表格2：问题统计

四个必选字段：山头、创建时间、产品序列号/机台编码、服务请求状态。四图统一使用用户所填年份，不再固定2026年，也不混用跨年分母。

| 图表 | 统计口径 |
| --- | --- |
| xxxx年各山头总问题数 | 所选年份内按山头分组计有效行数，每行一个问题，重复记录也计数 |
| xxxx年各山头月度问题出现次数及其变化趋势 | 同一年内起始月至结束月连续显示；对年度有效数据实际出现的每个山头绘制一条线，缺失月份补0 |
| xxxx年各个山头的问题密度 | 同一年度山头问题数 / 该山头非空机器编码去重数 |
| xxxx年各山头关闭率 | 去除状态首尾空格后，申请关闭、已结束、已取消的行数 / 同一年度山头问题数 |

年度指标包含该年所有有效记录，不受趋势起止月裁剪。仅绘制有效年度中实际出现的山头，未出现的标准山头不占位置。未知非空名称提示后保留，避免静默丢弃记录。

日期支持 `20xx-x-xx`、Excel 日期单元格及带时间的日期；无法解析的记录列出 Excel 行号并阻止生成。机器为空仍计问题数，不计机器数；状态为空仍计分母，不计关闭数，并提示。机器按山头分别去重，数字123与123.0相同，文本前导零保留。密度机器数为0时显示 N/A，关闭率总数为0时显示 N/A。所选年份或整个趋势范围无记录时提示“当前时间范围无有效数据”，不生成空白四图。

## 样式

所有图表标题：微软雅黑、16pt、加粗；PPT 同时指定中文字体以避免回退。默认柱形 `#ED7D31`，折线 `#5B9BD5`；多折线使用以蓝色开头的不同颜色序列。第一步支持顶部自定义配色并同步到预览与 PPT；第二步使用固定默认配色。

四图放在16:9页面上半部，下半部不加说明或占位框。来源和统计口径写入演讲者备注。数据量很大时标签会变密，应用不会自动截断记录。

## 验证与打包

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tests/validate_issues_layout.py
.\.venv\Scripts\python.exe tools/build_windows.py
```

测试使用模拟数据，覆盖统计、缺失值、映射、失效状态、PPT双轴和内嵌数据、四图布局及异常保存。验证脚本在 `outputs/问题统计功能验证/` 生成模拟工作簿、四页PPT和截图。`tests/render_powerpoint.ps1` 可用本机 PowerPoint 只读渲染，用于实际版式检查。

打包需安装 `requirements-build.txt`；配置已包含 pandas，输出到新的 `releases/<时间>/`。旧EXE不会随源码修改自动更新。`ExcelPPT.exe --self-test <目录>` 可运行打包后的导入、统计、导出检查。源码检查不等同于已验证新的EXE。
